# 파이썬 가계부 프로그램 (Budget Manager)

컴프 1 과제용으로 제작하는 간단하고 효율적인 개인 자산 관리를 위한 파이썬 기반 가계부 프로그램입니다.

## 1. 프로젝트 개요
사용자가 일상적인 수입과 지출을 기록할 수 있도록 돕는 도구입니다.

## 2. 주요 기능
- **수입/지출 내역 관리**: 날짜, 금액을 포함한 내역 추가, 조회, 수정, 삭제(CRUD) 기능.
- **데이터 저장**: 프로그램 종료 후에도 데이터가 유지되도록 파일(JSON) 시스템 활용.

## 3. 기술 스택
- Python 3
- Tkinter
