# 파이썬 가계부 프로그램 (Budget Manager)

컴프 1 과제용으로 제작하는 간단하고 효율적인 개인 자산 관리를 위한 파이썬 기반 가계부 프로그램입니다.

## 1. 프로젝트 개요
사용자가 일상적인 수입과 지출을 기록하고, 이를 카테고리별로 분류하여 소비 패턴을 분석할 수 있도록 돕는 도구입니다.

## 2. 주요 기능
- **수입/지출 내역 관리**: 날짜, 금액, 카테고리, 메모를 포함한 내역 추가, 조회, 수정, 삭제(CRUD) 기능.
- **카테고리 분류**: 식비, 교통비, 주거비, 월급 등 사용자가 정의한 카테고리별 관리.
- **데이터 저장**: 프로그램 종료 후에도 데이터가 유지되도록 파일(JSON 또는 SQLite) 시스템 활용.
- **통계 및 분석**: 월별 지출 합계, 카테고리별 소비 비중 시각화(텍스트 기반 또는 차트).
- **검색 기능**: 특정 기간이나 키워드를 통한 내역 검색.

## 3. 기술 스택
- **언어**: Python 3.x
- **데이터베이스/저장**: SQLite3 (내장 라이브러리) 또는 JSON 파일
- **사용 라이브러리**:
  - `datetime`: 날짜 관리
  - `tabulate` (선택 사항): 터미널 출력 결과 시각화

## 4. 설치 및 실행 방법 (예정)
```bash
# 저장소 클론
git clone <repository-url>

# 프로그램 실행
python main.py
```
